# PARTSCTRL - historial de movimientos en memoria

Ejecutar desde la terminal:

```bash
python main.py
```

El historial de movimientos se guarda en una lista llamada `movimientos`.
No se escribe ningún archivo.

Se registran:
- ALTA: cuando se agrega una autoparte.
- MODIFICACIÓN: cuando se modifica una autoparte.
- BAJA: cuando se elimina una autoparte.

La opción 6 permite consultar el historial durante la ejecución.

Al cerrar el programa, el historial se pierde, tal como fue solicitado.
